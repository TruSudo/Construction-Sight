# Phase 3 — locally built OSM basemap, 2026-10-14

The map uses locally built dark raster PMTiles from Geofabrik's lawful public Southern California OSM extract, not hosted Protomaps downloads. Builder verifies the input SHA-256, uses open-source Pyosmium/Pillow/PMTiles, retains source metadata and displays OSM/ODbL attribution. User menu installs the resulting archive with hash verification; map tiles, city labels and SVG highway shields load locally. Optional authorized HTTPS provider settings accept the user's own key in the tile URL. Inland Empire core coverage is explicit: west/east -118/-116.75, south/north 33.55/34.5, native zoom 6–13; higher zoom enlarges tiles and outside coverage shows the grid. OSM context does not verify project facts.

Affected hash/build/tile/installation tests and browser local-only tiles/shields/attribution/zoom checks pass; full-suite and blocking-gate results are recorded in PR. Site Map is complete with a regional archive installation step; two controls remain partial (31/33 complete). Native fidelity and unknown-type limitations remain reported.
